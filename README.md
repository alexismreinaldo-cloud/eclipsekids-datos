# Eclipse Kids – datos de las páginas

Datos que leen las páginas de https://eclipsekidsapp.com.ar sin tener que volver a publicar el sitio.

- `d/` páginas de cada familia, **cifradas** (solo se abren con el link de esa familia).
- `f/` fotos de los homenajeados, **cifradas**.
- `consulta.json` datos públicos de la página de consultas.

Se actualiza solo con `tools/publicar.mjs`.
